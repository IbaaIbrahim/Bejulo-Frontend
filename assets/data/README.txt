world.geojson
  Country polygons for the Projects map.

  Source : Natural Earth, ne_110m_admin_0_countries (public domain, no
           attribution required — https://www.naturalearthdata.com/about/terms-of-use/)
  Changes: all properties stripped, coordinates rounded to 2 decimals
           (~1 km), degenerate rings dropped. 838 KB -> 163 KB.

  It replaces raster basemap tiles so the map matches the flat grey artwork in
  the Figma/PDF design, and so the page makes no third-party requests.
